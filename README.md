
# Student Grade Analyzer

## About the Project
Student Grade Analyzer is a Python program designed to manage and analyze student grades.

## Features
- Add student names and grades.
- Display all student records.
- Calculate the average grade.
- Find the highest grade.
- Find the lowest grade.
- Validate student grades.

## Technologies Used
- Python 3

## How to Run
1. Download the project.
2. Open the terminal.
3. Run:

```bash
python student_analyzer.py
```

## Project Purpose
This project was created to practice Python programming, functions, loops, lists, and data analysis.
